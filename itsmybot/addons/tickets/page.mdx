# Tickets Plugins
The tickets plugin allows you to create tickets in your server.

## Create a category
You can create a unlimited amount of categories. Each category can have a different configuration. You just need to create a new file in the `configs/Tickets/categories/` folder or subfolder.

## Commands
<Properties>
  <Property name="/add <user>">
    Add a user to the ticket.
  </Property>
  <Property name="/remove <user>">
    Remove a user from the ticket.
  </Property>
  <Property name="/claim">
    Claim the ticket.
  </Property>
  <Property name="/rename">
    Rename the ticket.
  </Property>
  <Property name="/transcript [channel]">
    Get the transcript of the channel.
  </Property>
  <Property name="/close [reason]">
    Close the ticket.
  </Property>
  <Property name="/tickets panel <panel>">
    Create a ticket creation panel.
  </Property>
  <Property name="/tickets history [user]">
    Get the ticket history of a user.
  </Property>
</Properties>

## Placeholders
<Properties>
  <Property name="%tickets_ticket_amount%">
    The amount of tickets.
  </Property>
</Properties>

## Button Custom ID
Allows you to have custom buttons to execute various actions of the Tickets addon at any location of the bot
<Properties>
  <Property name="tickets_create_<category-id>">
    Replace <category-id> with your category's filename like "categories/support.yml" → "ticket_create_support"
  </Property>
</Properties>

<CodeGroup>
```yaml {{ title: 'Example' }}
  - type: button
    label: "Open a Support Ticket"
    custom-id: "tickets_create_support"
    emoji: "📩"
    style: 'Secondary'
```
</CodeGroup>
